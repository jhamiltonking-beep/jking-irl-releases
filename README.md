# JKing IRL releases

Release APKs and `update.json` for the JKing IRL app's in-app updater. No source code here.

- Latest APK: see [Releases](https://github.com/jhamiltonking-beep/jking-irl-releases/releases/latest)
- The app reads `releases/latest/download/update.json` and checks the APK's SHA-256 and signing key before installing.
